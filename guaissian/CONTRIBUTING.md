# Contributing

Thank you for helping audit this work.

Create a branch for each focused change and submit it through a pull request.
Explain what claim is affected, what was checked, how to reproduce the check,
and what remains uncertain.

Please distinguish among:

- an algebraic derivation;
- a floating-point experiment;
- a rigorous interval or ball-arithmetic enclosure;
- an exact structural check;
- an assumption such as RH.

Corrections are welcome. A negative result or a discovered flaw is useful
progress and should be documented rather than hidden.
