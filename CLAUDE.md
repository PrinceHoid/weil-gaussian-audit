# Claude project instructions

Follow `AGENTS.md`.

Begin with `docs/CURRENT_STATE.md`, then read only the assigned GitHub issue and
the files listed in its **Inputs** section.

Do not review the complete repository, all open pull requests, or unchanged
history unless the assigned issue explicitly requires that scope.

Work on one exact claim at a time. Do not propose extensions or new routes unless
the issue authorizes them. End with the short issue handoff required by
`AGENTS.md`.
