## Exact candidate claim

Let

```text
h_t(r) = exp(-(r-t)^2) + exp(-(r+t)^2).
```

In the declared Schwartz-space topology, the closed positive cone generated by
the functions `h_t` does not contain the narrower centered Gaussian
`exp(-a r^2)` when `a > 1`.

A positive cone means finite sums

```text
c_1 h_{t_1} + ... + c_n h_{t_n},   c_j >= 0,
```

plus limits in the explicitly declared topology.

## Proposed proof mechanism

Use the linear functional

```text
Lambda(f) = integral_R f(r) dr - sqrt(pi) f(0).
```

The proposed argument is:

1. `Lambda(h_t) = 2 sqrt(pi) (1 - exp(-t^2)) >= 0`.
2. Linearity makes `Lambda` nonnegative on finite positive mixtures.
3. Continuity in the declared topology extends this to the closed cone.
4. For `a > 1`,
   `Lambda(exp(-a r^2)) = sqrt(pi) (a^(-1/2) - 1) < 0`.
5. Therefore the narrower Gaussian is outside the closed positive cone.
